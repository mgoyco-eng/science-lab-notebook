# Science Lab Notebook — GitHub Pages Build (v4)

Static Science Lab Notebook designed for supervised in-class report writing.

This version includes the revised editable table system with blank table titles, blank editable column headings, and optional grouped headings that can span adjacent columns. It also preserves the prior Focus Mode, assessment monitoring, preview, PDF download, no-save behavior, and preview/PDF-only student watermark.

Upload `index.html`, `styles.css`, and `app.js` to the root of the GitHub Pages repository.
